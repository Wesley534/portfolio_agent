# Vulnerability Assessment & Penetration Testing

**Category:** Security Engineering
**Status:** Completed

## Description
Conducted VAPT assessments covering network scanning, vulnerability identification, and security control validation. Documented findings with risk ratings and remediation recommendations. Applied OWASP guidelines to web application assessments including SQL injection, XSS, CSRF, and authentication bypass testing.

## Architecture Decisions
- Systematic VAPT methodology with defined scope and rules of engagement
- Nmap for network discovery and port scanning
- Burp Suite for web application vulnerability testing
- OWASP Top 10 as the baseline for web application assessment
- Risk-rated findings with prioritized remediation recommendations
- Documentation of methodologies, findings, and remediation steps

## Tech Stack
VAPT, OWASP, Nmap, Burp Suite, Risk Assessment, Web Security, Network Scanning

## Highlight
Structured security assessment methodology with actionable remediation documentation
