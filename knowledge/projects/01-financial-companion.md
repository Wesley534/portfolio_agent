# Financial Companion

**Category:** Backend Engineering
**Status:** Deployed (financialcompanion.netlify.app)

## Description
A full-stack personal finance application with a FastAPI backend and React frontend. Designed with Alembic-managed database migrations for schema evolution, SQLAlchemy ORM for data integrity, and AI-powered helpers for transaction categorization.

## Architecture Decisions
- Separates API logic from business rules, making the system testable and maintainable
- Alembic migrations allow the schema to evolve with the application
- SQLAlchemy provides data integrity with type-safe queries

## Tech Stack
FastAPI, Python, React.js, TypeScript, Vite, SQLAlchemy, Alembic

## Highlight
Production deployment with automated database migrations and AI integration
