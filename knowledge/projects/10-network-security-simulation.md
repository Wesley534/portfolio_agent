# Network Security Simulation

**Category:** Security Engineering
**Status:** Completed

## Description
Configured Linux-based server environments and network monitoring tools to identify and mitigate simulated security threats. Used Wireshark for packet analysis and iptables for firewall rule implementation. Validated security controls against common attack vectors including port scans, unauthorized access attempts, and network reconnaissance.

## Architecture Decisions
- Linux server environment with simulated production traffic
- Wireshark for deep packet inspection and traffic analysis
- iptables for firewall rule implementation and access control
- Hands-on validation of security controls against live attack simulations
- Documentation of detection patterns and mitigation strategies

## Tech Stack
Linux, Wireshark, iptables, Network Security, Threat Detection, Bash

## Highlight
Hands-on network defense with packet analysis and firewall configuration
