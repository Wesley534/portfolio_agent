# Stellar Donation Platform

**Category:** Blockchain Infrastructure

## Description
A React-based donation platform integrated with Stellar blockchain for transparent, tamper-proof donation tracking. Express backend handles server-side logic with Stellar SDK integration. The React frontend provides donation campaign management, transaction history, and real-time balance display.

## Architecture Decisions
- React SPA for the donation user interface
- Express.js backend with Stellar SDK
- Blockchain-backed transparency for donation tracking
- JavaScript with responsive design patterns

## Tech Stack
React.js, Stellar, Express.js, JavaScript, Vite

## Highlight
Blockchain-backed donation transparency with Express middleware
