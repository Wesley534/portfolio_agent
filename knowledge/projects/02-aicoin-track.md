# AiCointrack — Crypto Transaction Tracker

**Category:** Backend Engineering
**Status:** Repository only

## Description
A cross-platform crypto tracking application with a Flutter mobile frontend, FastAPI backend, and Firebase authentication. Features JWT-based access tokens, MySQL with Alembic migrations, and HuggingFace AI analytics. The mobile UI is built with Flutter and Dart, providing a native experience on both iOS and Android.

## Architecture Decisions
- Multi-platform architecture with Flutter for mobile and FastAPI for backend
- JWT authentication for secure API access
- Firebase for authentication provider
- AI analytics via HuggingFace for transaction insights
- Flutter's widget system enables responsive layouts across device sizes

## Tech Stack
Flutter, Dart, FastAPI, Python, Firebase, MySQL, Alembic, JWT

## Highlight
Multi-platform architecture with Firebase Auth + JWT and AI-powered analytics
